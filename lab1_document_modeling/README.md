# Лабораторна робота №1 — Моделювання електронного документа

**Дисципліна:** Системи електронного документообігу
**Варіант:** 8 — Заява працівника на відпустку

## Мета роботи

Навчитися представляти електронний документ як набір структурованих
даних у форматі JSON, реалізувати читання документів засобами Python,
перевірку обов'язкових полів та унікальності ідентифікаторів.

## Опис документа

Документ моделює заяву працівника на відпустку. Містить загальні поля
(id, type, title, author, created_at, status, version) та додаткові
поля свого варіанта (employee_id, department, vacation_start,
vacation_end).

## Структура проєкту
lab1_document_model/
├── main.py
├── README.md
└── documents/
├── doc_001.json
├── doc_002.json
├── doc_003.json
└── doc_004.json

## Таблиця полів

| Поле | Тип | Обов'язкове | Призначення | Приклад |
|---|---|---|---|---|
| id | string | так | унікальний ідентифікатор | DOC-001 |
| type | string | так | тип документа | vacation_request |
| title | string | так | назва | Заява на щорічну відпустку |
| author | string | так | автор | Коваленко Марія Петрівна |
| created_at | string | так | дата створення | 2026-08-20 |
| status | string | так | поточний статус | approved |
| version | number | так | номер версії | 1 |
| employee_id | string | так | ідентифікатор працівника | EMP-101 |
| department | string | так | відділ | Відділ маркетингу |
| vacation_start | string | так | дата початку відпустки | 2026-09-15 |
| vacation_end | string | так | дата закінчення відпустки | 2026-09-28 |

## Функціонал програми (main.py)

- автоматичний пошук усіх `.json` файлів у каталозі `documents/`
  (додавання нового файлу не потребує зміни коду);
- читання та парсинг JSON-документів;
- перевірка наявності всіх обов'язкових полів;
- перевірка унікальності `id` серед усіх документів;
- виведення інформації про коректні документи;
- повідомлення про помилки для некоректних документів
  (відсутні поля, дублікат id, синтаксична помилка JSON).

2. **Дублікат id** — встановлено однаковий `id: "DOC-001"` у двох

   автоматично знайшла та коректно обробила новий файл без будь-яких

## Висновок

У результаті виконання лабораторної роботи реалізовано модель
електронного документа (заяви на відпустку) у форматі JSON та
програму на Python, яка автоматично знаходить, читає та перевіряє
структуру документів у каталозі. Отримано практичні навички роботи
з JSON, стандартною бібліотекою Python (`json`, `pathlib`) та
принципами валідації структурованих даних.
