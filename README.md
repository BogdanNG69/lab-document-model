# Системи електронного документообігу — Лабораторні роботи

Репозиторій містить виконані лабораторні роботи з дисципліни
«Системи електронного документообігу». Усі роботи виконані за
**Варіантом 8** (кадрові документи / заява працівника на відпустку)
і послідовно розширюють одну й ту саму модель документа.

## Структура репозиторію
lab1_document_model/
├── lab1_document_modeling/ — Лабораторна робота №1
├── lab2_document_lifecycle/ — Лабораторна робота №2
└── lab3_document_storage/ — Лабораторна робота №3

## Лабораторна робота №1 — Моделювання електронного документа

Папка: [`lab1_document_modeling/`](./lab1_document_modeling)

Представлення електронного документа у форматі JSON, читання
документів засобами Python, перевірка обов'язкових полів та
унікальності ідентифікаторів.

**Технології:** Python, модуль `json`, `pathlib`

## Лабораторна робота №2 — Життєвий цикл та версійність

Папка: [`lab2_document_lifecycle/`](./lab2_document_lifecycle)

Розширення моделі документа: дозволені переходи між статусами,
історія змін, версійність при редагуванні змістовних полів.

**Технології:** Python, `json`, `datetime`

## Лабораторна робота №3 — Файлова система та SQLite

Папка: [`lab3_document_storage/`](./lab3_document_storage)

Розділення метаданих документа (SQLite) та вмісту документа
(текстові файли). Пошук за кількома критеріями, захист від
дублювання ідентифікаторів, параметризовані SQL-запити.

**Технології:** Python, `sqlite3`, `pathlib`
