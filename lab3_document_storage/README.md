# Лабораторна робота №3 — Зберігання електронних документів: файлова система та SQLite

**Дисципліна:** Системи електронного документообігу
**Варіант:** 8 — Кадрові документи

## Опис

Реалізовано модель зберігання електронних документів, у якій метадані
зберігаються в базі даних SQLite, а вміст документів — окремими
текстовими файлами у файловій системі. Записи в базі пов'язані з
файлами через поле `file_path`.

## Структура таблиці documents

| Поле | Тип SQLite | Призначення |
|---|---|---|
| id | TEXT PRIMARY KEY | унікальний ідентифікатор |
| type | TEXT | тип документа |
| title | TEXT | назва |
| author | TEXT | автор |
| created_at | TEXT | дата створення |
| status | TEXT | статус |
| version | INTEGER | версія |
| file_path | TEXT | шлях до файлу документа |
| employee_id | TEXT | ідентифікатор працівника |
| department | TEXT | відділ |

## Структура проєкту
lab3_document_storage/
├── main.py
├── documents.db — створюється автоматично при першому запуску
└── storage/
├── doc_001.txt
├── doc_002.txt
├── doc_003.txt
├── doc_004.txt
└── doc_005.txt

## Запуск
py main.py


## Функціонал

- підключення до SQLite, автоматичне створення таблиці `documents`;
- додавання документів з перевіркою наявності файлу перед записом;
- захист від дублювання `id` (PRIMARY KEY + обробка IntegrityError);
- параметризовані SQL-запити (захист від SQL injection);
- виведення списку всіх документів;
- пошук за id;
- пошук за employee_id (працівник);
- пошук за department (відділ);
- читання вмісту текстового файлу знайденого документа.

## Результати перевірок

1. Звичайний пошук за ID — документ DOC-002 знайдено, виведено повні метадані.
2. Пошук неіснуючого ID (DOC-777) — коректне повідомлення про відсутність.
3. Спроба додати документ з уже існуючим id (DOC-001) — відхилено, дублікат не створено.
4. Спроба додати документ з неіснуючим file_path — виявлено відсутність файлу, запис не додано.
5. Пошук за employee_id та department — знайдено відповідні документи.
6. Читання вмісту файлу знайденого документа (DOC-003) — вміст успішно виведено в консоль.
